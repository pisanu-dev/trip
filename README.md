# China Autumn Brochure

A self-contained Thai HTML brochure for 18-24 October 2026.
Images and the Thai font are embedded in index.html. No installation or build is required.

## Publish with GitHub Pages
1. Create a public repository such as china-autumn-2026.
2. Upload index.html and .nojekyll to the repository root and commit to main.
3. Open Settings > Pages.
4. Select Deploy from a branch, main, and /(root), then Save.
5. Wait for the Pages deployment to finish and open the URL shown by GitHub.

The site and repository will be public. There are no account credentials in this package.
Photo attributions and license links are included at the bottom of the brochure.
The itinerary and prices remain estimates, not confirmed reservations.
